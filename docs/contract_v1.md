# banto 契約 v1(凍結)

これは banto のすべての参加者(人間・AI・製品)が従う唯一の共通契約である。
この文書は意図的に短い。**この文書に収まらないものは、契約ではなく参加者のローカルな都合である。**

## 封筒(envelope)

イベントは JSONL の1行。行は下記フィールドを持つ JSON オブジェクトの**正準形**でなければならない。

| フィールド | 型 | 規則 |
|---|---|---|
| `schema` | string | 常に `"banto/1"` |
| `seq` | int | 0 始まりの密な連番 |
| `prev` | string \| null | 直前イベントの `id`。先頭イベントのみ `null` |
| `ts` | string | RFC 3339 タイムスタンプ |
| `actor` | string | 書き手。人間 (`"keisuke"`) または AI (`"agent:claude"`) |
| `type` | string | 小文字ドット区切りの語彙名(例 `video.log`)。語彙は types_v1.md |
| `body` | object | 自由。意味は受信側が解釈する |
| `evidence` | array | 一次証拠への参照。`{sha256, uri?, media_type?, bytes?}` の配列(空可) |
| `op` | string | 任意。冪等キー。同じ `op` の再送は同一イベントを返す |
| `id` | string | `id` を除く封筒の正準形 JSON の SHA-256(小文字 hex) |

正準形: UTF-8、キーはバイト順ソート、区切りは `,` と `:`(空白なし)、非有限数は禁止。
`op` は未設定なら省略。`evidence` 内の `uri`/`media_type`/`bytes` も未設定なら省略。他のフィールドは常に存在する。

## 不変量

1. **追記専用。** 一次記録は編集も削除もしない。修正は新しいイベントとして追記する(慣例: `body.re` に対象イベントの `id`)。
2. **主張は一次証拠へ結ぶ。** 完了・成立を意味するイベント(`claim.declare` 等)は `evidence` を伴う。要約・伝聞・自己評価は証拠にならない。
3. **完了主張と検証済み成立は別物。** `claim.declare` は実行者の主張にすぎない。独立した actor による `claim.verify` だけが成立を与える。
4. **確信度は記録しても判定に使わない。** 偽完了の自己確信は真完了と同じ高さである(bgit G-2: 確信度ゲートの捕捉率 0.081)。
5. **書くときは摩擦ゼロ、読むときに厳格。** 人間に要求してよい入力は1ジェスチャーまで。整理規則は導出層(読み手)に住む。
6. **台帳は購読者であり、権威ではない。** 導出ビュー(brief、在庫、近況)はいつでも作り直せる。

## 改訂

この契約の改訂は編集ではなく版上げ(`banto/2`)であり、それ自体をイベントとして台帳に記録する。
