2. **サブ観の作り方**: 各 Source 単独 + 同一質問で独立コール
3. **不一致の判定規則**: 両者 abstain → 一致 / 片方のみ abstain → **不一致** /
   両者回答 → 内容語 Jaccard ≥ 0.5 で一致 (Phase 1 §6 の凍結規則そのまま)
4. **発火条件**: サブ観の不一致 ∧ 全体観の回答が非棄権

   金キートークン ≥60%)

7. エージェント/プロンプト/モデル設定は Phase 1 と同一 (gpt-5-mini,
   reasoning_effort=minimal)。他の v1.1 プローブ (再現性/挙動不変量/保存量)

## 2. 独立データセット (本文書コミット後に生成)

Phase 1 の 90 問とトピック・値を重複させない新規 60 問:
- **Set D (矛盾 2 源, 30 問)**: 矛盾の型を多様化 — 数値 / 年代 / 帰属
  (人物) / 場所 / 単位。正解 = 棄権。**偽完了ラベルは構造フィールド
  (abstain) から機械的に決まり、採点雑音を含まない** (Phase 1 の教訓)
- **Set E1 (冗長整合 2 源, 15 問)**: 両 Source が同一の答えを異なる表現で
  主張。正解 = 回答。分割被覆プローブの誤発火対照
- **Set E2 (分割整合 2 源, 15 問)**: 答えが両 Source の結合を要求
